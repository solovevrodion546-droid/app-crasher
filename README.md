# AppCrasher - Приложение для вылета приложений на Android

💥 Приложение, которое выплёчивает другие приложения на Android без ADB!

## Как работает:
- Выбираешь приложение из списка
- Нажимаешь "💥 ВЫПЛЕТЕТЬ!"
- Приложение мгновенно закрывается через `am force-stop`

## Установка:
1. Собираем APK через GitHub Actions
2. Скачиваем из Artifacts
3. Устанавливаем на телефон

## Требования:
- Android 5.0+ (API 21+)
- Разрешение на установку из неизвестных источников
